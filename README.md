Multi-Step Data Collector 🚀
Простой и интуитивно понятный интерфейс для поэтапного сбора данных. Проект реализует трехшаговую форму, обеспечивая сохранение состояния между этапами и валидацию введенных данных.
Особенности
Пошаговый процесс: Данные разбиты на логические блоки для удобства пользователя.
Сохранение прогресса: Возможность возвращаться на предыдущие шаги без потери данных.
Адаптивный дизайн: Интерфейс корректно отображается на любых устройствах.
Стек технологий
React — основа фронтенд-части.
Zustand — легкий и быстрый менеджер состояний для управления данными формы.
Mantine UI — библиотека готовых компонентов для создания современного и доступного дизайна.
Как запустить
Склонируйте репозиторий.
Установите зависимости: npm install.
